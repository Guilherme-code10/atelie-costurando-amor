# 🧵 Ateliê Costurando Amor

Projeto web desenvolvido como atividade acadêmica, com foco na criação de um site para um projeto social fictício dedicado à confecção de bonecas e bonecos para crianças.

## 📌 Páginas

- **Início** — apresentação do projeto e sua missão
- **Projetos** — informações sobre voluntariado e doações
- **Cadastro** — formulário para cadastro de voluntários

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsividade
- Git
- GitHub

## 📱 Responsividade

O layout utiliza media queries para adaptar a navegação e a disposição do conteúdo em diferentes tamanhos de tela.

```text
Atividade-2-/

├── projeto.html
```

## 🎓 Objetivo acadêmico

O projeto foi desenvolvido para praticar estruturação de páginas HTML, estilização com CSS, formulários, organização de conteúdo, Grid, Flexbox e conceitos de responsividade.
